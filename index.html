常见问题
提示「Windows 已保护你的电脑」怎么办？

这些程序都没买代码签名证书，第一次运行会弹 SmartScreen。点 「更多信息」→「仍要运行」 即可。不是报毒，是没签名的例行提示。

下载下来打不开 / 解压报错？

多半是没下完整。每个包旁边标了 SHA-256 前 8 位，下载后可以核对；值对不上说明传输中断，重新下一次就好。国内访问 GitHub 时快时慢，属于正常现象。

为什么文件名是英文的？

GitHub 的发布附件不支持中文文件名，会被吞成 01_.zip 这种。所以安装包用英文命名，页面上的标题和说明仍然是中文，一一对应，不影响使用。

哪个最省事？

磁盘清理助手、LUT 生成器、视频音频提取器 都是零配置，解压双击就完事。语音助手要先装 Python（包内有五分钟指南），1.5 GB 主要是语音模型。

需要联网吗？

除了实时翻译（要调翻译接口）和 NetPulse（要测网速），其余工具全部离线运行，不采集任何使用数据。
